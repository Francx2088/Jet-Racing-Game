# Sky Racing 🏎️

A 3D sky-racing browser game (three.js). Open `index.html` through any static server.

- 8 levels, each with its own track, sky, weather, car and twist
- Controls follow the device: desktop = arrow keys (A/D) + Space/Up to boost; landscape phone = two arrow buttons + BOOST; portrait phone = thumb slider + BOOST.
- Boost pads and nitro help every car, rivals included. Hazards: crates, cones, sliding bars, spinners, gates and lasers.
- Files: `track.js` (track generator), `levels.js` (level data), `world.js` (sky, road, scenery), `cars.js` (car models), `game.js` (gameplay, HUD, audio)
- No platform SDK is integrated yet.
